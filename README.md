# 📩 SMS Spam Classifier

A Machine Learning based SMS Spam Detection web application built using Python, Streamlit, and Scikit-learn.

The application predicts whether a message is **Spam** or **Not Spam** using trained NLP and ML models.

---

## 🚀 Features

* SMS Spam Detection
* Text Preprocessing
* TF-IDF Vectorization
* Real-time Prediction
* Streamlit Web Interface
* Fast and Lightweight

---

## 🛠️ Tech Stack

* Python
* Streamlit
* Scikit-learn
* Pandas
* NumPy
* TF-IDF

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/Satishkumar683/emailnsms-classifier
cd smsclassifier
```

---

### 2. Create Virtual Environment

```bash
python -m venv myenv
```

Activate environment:

#### Windows

```bash
myenv\Scripts\activate
```

#### Linux / Mac

```bash
source myenv/bin/activate
```

---

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run Application

```bash
streamlit run app.py
```

Open browser:

```bash
http://localhost:8501
```
